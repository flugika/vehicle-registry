# API

Base URL: `http://localhost:3001/api`

response สำเร็จจะอยู่ใน `{ "data": ... }` ถ้า error จะได้ `{ "message": "..." }`

## ข้อมูลรถ

| ฟิลด์ | จำเป็น | หมายเหตุ |
| --- | --- | --- |
| registrationNumber | ใช่ | ไม่เกิน 20 ตัว ห้ามซ้ำ |
| brand | ใช่ | ไม่เกิน 50 ตัว |
| model | ใช่ | ไม่เกิน 50 ตัว |
| color | ไม่ | ไม่เกิน 30 ตัว |
| year | ไม่ | 1886 - 2100 |
| notes | ไม่ | ไม่เกิน 1000 ตัว |

## Endpoints

| Method | Path | ทำอะไร | Status |
| --- | --- | --- | --- |
| GET | /vehicles | ดูรถทั้งหมด (ใหม่สุดก่อน) | 200 |
| GET | /vehicles/:id | ดูรถ 1 คัน | 200, 404 |
| POST | /vehicles | เพิ่มรถ | 201, 400, 409 |
| PATCH | /vehicles/:id | แก้ไขรถ (ส่งเฉพาะฟิลด์ที่แก้) | 200, 400, 404, 409 |
| DELETE | /vehicles/:id | ลบรถ | 204, 404 |

- 400 = ข้อมูลไม่ถูกต้อง
- 404 = ไม่พบรถ
- 409 = ทะเบียนซ้ำ
